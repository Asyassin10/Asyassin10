## 🛡️ Valhalla — My PHP Framework

<div align="center">
  <img src="https://www.valhalla-fremwrok.space/valhalla-logo.png" alt="Valhalla Framework" width="120px" />
</div>

<br/>

> *Laravel is too heavy. Slim is too bare. Lumen is deprecated. So I built Valhalla.*

**[Valhalla](https://valhalla-fremwrok.space)** is a microservices-first PHP framework I designed and built from scratch — for developers who want fast JSON APIs, clean architecture, service-to-service communication, and a real CLI, without dragging a monolith into every service.

**PHP 8.2+ · ~300KB · MIT · 2 runtime dependencies · v1.0**

### Why it exists

Most PHP frameworks weren't designed for microservices. They carry session handling, template engines, and ORMs that have no place in a focused internal service. Valhalla is scoped to exactly what a backend service needs — and nothing else.

### What ships with it

| Feature | Details |
|--------|---------|
| ⚡ Lightweight core | ~300KB, boots in milliseconds, no hidden dependencies |
| 🔧 CLI scaffolding (28 commands) | Generate projects, controllers, middleware, services, auth flows, agents from the terminal |
| 🔐 JWT & API token auth | First-class auth with middleware enforcement and zero-config defaults |
| 🔗 Service-to-service client | Typed HTTP client with retries, timeouts, bearer tokens and tracing-ready headers |
| 🤖 Local agent workers | MCP-style long-running PHP workers — scoring, summarization, background tasks |
| 🗄️ Pluggable ORM | Install Eloquent or Doctrine, only one driver at a time, only what you need |
| 🐳 Container scaffolding | Docker & Podman setup in one command — PHP, MySQL/Postgres, Redis, queues |
| 📋 API-first responses | Every route returns structured JSON by default. No view layer, no template engine |
